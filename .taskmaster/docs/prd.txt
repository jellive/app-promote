## 1. 개요 (Overview)

### 1.1 프로젝트 배경
현재 포트폴리오 사이트(app-promote)는 회사 프로젝트 3개(KnowRecorder, KnowLounge, Alo)만 표시하고 있음.
2024-08 ~ 2025-11 기간 동안 완료한 개인 프로젝트 8개를 추가하여 Full-Stack 개발 역량을 증명하는
포트폴리오로 리브랜딩 필요.

### 1.2 목표
- 8개 완료 프로젝트 (Production 6개 + Archive 2개) 전시
- 기술 스택 및 역량 시각화
- 프로젝트별 상세 페이지 제공
- 반응형 디자인 및 다크모드 지원
- 성능 최적화 (Core Web Vitals 준수)

### 1.3 기술 스택
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript 5.x
- **Styling**: Tailwind CSS 3.4 + shadcn/ui
- **Testing**: Jest + React Testing Library + Playwright (E2E)
- **CI/CD**: GitHub Actions

## 5. 개발 가이드라인 (Development Guidelines)

### 5.1 TDD (Test-Driven Development) - 필수 준수

#### 5.1.1 TDD 원칙
```yaml
tdd_cycle:
  RED: "실패하는 테스트 먼저 작성"
  GREEN: "테스트를 통과하는 최소한의 코드 작성"
  REFACTOR: "코드 개선 (테스트 유지)"

coverage_targets:
  unit_tests: ">= 90%"
  integration_tests: ">= 80%"
  overall: ">= 80%"
  new_code: "100%"
```

#### 5.1.2 테스트 유형별 가이드

**단위 테스트 (Unit Tests) - Jest + React Testing Library**
```yaml
target:
  - 모든 컴포넌트
  - 유틸리티 함수
  - 커스텀 훅

naming_convention: "[ComponentName].test.tsx"

example_structure:
  - "describe('ComponentName', () => {...})"
  - "it('should render correctly', () => {...})"
  - "it('should handle [specific behavior]', () => {...})"
```

**통합 테스트 (Integration Tests)**
```yaml
target:
  - 페이지 컴포넌트
  - API 라우트
  - 데이터 페칭

focus:
  - 컴포넌트 간 상호작용
  - 라우팅 동작
  - 상태 관리
```

**E2E 테스트 (Playwright)**
```yaml
target:
  - 주요 사용자 플로우
  - 네비게이션
  - 폼 제출
  - 반응형 동작

browsers:
  - Chrome
  - Firefox
  - Safari

devices:
  - Desktop (1920x1080)
  - Tablet (768x1024)
  - Mobile (375x667)
```

#### 5.1.3 TDD 워크플로우

```yaml
step_1_red:
  action: "테스트 파일 생성"
  command: "npm run test -- --watch"
  expected: "테스트 실패 (빨간색)"

step_2_green:
  action: "최소한의 구현 코드 작성"
  expected: "테스트 통과 (초록색)"

step_3_refactor:
  action: "코드 품질 개선"
  constraints:
    - "테스트 계속 통과"
    - "중복 제거"
    - "가독성 향상"

step_4_commit:
  action: "변경사항 커밋"
  message_format: "[Test/Feature/Fix]: 설명"
```

### 5.2 코드 스타일

```yaml
linting:
  tool: "ESLint"
  config: "eslint-config-next"
  rules:
    - "no-unused-vars: error"
    - "prefer-const: error"

formatting:
  tool: "Prettier"
  config:
    semi: false
    singleQuote: true
    tabWidth: 2
    trailingComma: "es5"

  strict: true
  noImplicitAny: true
  noUnusedLocals: true
```

### 5.3 커밋 컨벤션

```yaml
format: "<type>: <subject>"

types:
  feat: "새 기능"

  docs: "문서 수정"
```
